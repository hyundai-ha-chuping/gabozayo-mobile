# 가보자요 휴대폰 앱

> 아이 취향에 맞는 나들이 장소를 골라 찜하고, "가보자요!" 한 번으로 차량에 보내는 가족 나들이 앱

팀 **夏秋핑** · 현대자동차그룹 차량용 앱 개발 공모전 출품작
짝꿍 앱(차량): https://github.com/hyundai-ha-chuping/gabozayo-car

## 이런 앱이다

나들이 장소를 고르는 일은 집에서 이루어지고, 길 안내는 차에서 필요하다. 가보자요 휴대폰 앱은 아이 취향으로 장소를 추천하고, 고른 장소를 6자리 연결 코드로 차량 앱에 넘긴다. 차에 타면 같은 장소가 차량 화면에서 기다리고 있다.

## 5분 만에 둘러보기

1. 폰 에뮬레이터에 APK를 설치한다.
   ```bash
   adb install -r apk/夏秋핑_가보자요폰_release.apk
   ```
2. 앱을 열고 시작 버튼을 누르면 소개 4장이 나온 뒤 홈으로 간다. 계정 없이 바로 쓴다. 위치 권한을 허용하면 현재 지역의 날씨와 추천이 나온다.
3. **내 정보**에서 **+ 아이 추가**로 아이를 등록하고 취향(동물, 곤충, 물놀이 등)을 고른다. 홈의 추천이 아이 취향으로 바뀐다.
4. 장소를 눌러 상세를 보고 **찜**한다. 지도에서도 주변 장소를 볼 수 있다.
5. **내 정보 → 내 차량**에서 6자리 연결 코드를 확인하고, 차량 앱에 입력한다.
6. 장소 상세의 **차량으로 보내기**를 누르면 차량 앱이 경로를 만들고, 폰 화면에 `경로 요청 중 → 경로 준비됨 → 안내 중` 상태와 도착 예정 시간·거리가 표시된다.
7. **이야기** 탭에서 후기·질문·꿀팁을 쓰고 좋아요와 댓글을 달 수 있다. 같은 연결 코드를 쓰는 가족끼리 글을 함께 본다.

## 주요 기능

| 영역 | 내용 |
|---|---|
| 홈 | 현재 지역의 날씨, 오늘의 행사(좌우로 넘김), 추천 장소, 아이 취향 추천 |
| 검색 | 장소·행사 검색, 인기 검색어 |
| 상세 | 사진 여러 장 넘겨 보기, 운영시간·휴무·이용연령·편의시설, 지도, 후기, 찜, 차량으로 보내기 |
| 지도 | 앱 안 지도에 장소와 현재 위치 표시, 카드를 누르면 **자세히 보기** |
| 찜 | 찜 목록. 찜하면 차량 앱 **찜**에 바로 나타남 |
| 이야기 | 후기·질문·꿀팁 글쓰기·검색, 좋아요, 댓글, 내가 쓴 글 (서버에 저장) |
| 내 정보 | 아이 관리, 아이별 취향 고르기, 가족 관심사 순위, 최근 본 장소, 차량 연결 |
| 차량 연결 | 6자리 연결 코드, 연결 상태, 보낸 목적지의 경로 진행 상태·시간·거리 |
| 설정 | 라이트/다크/휴대폰 설정 따르기, 위치 권한, 기록 지우기, **내 데이터 모두 삭제** |

## 화면 흐름

```
시작 화면 -> 소개 -> 홈 / 찜 / 이야기 / 내 정보  (하단 메뉴)
                    ├ 검색 -> 검색 결과 -> 상세 -> 지도 · 후기 · 차량으로 보내기
                    └ 내 정보 -> 아이 관리 · 취향 고르기 · 최근 본 장소 · 차량 연결 · 설정
```

## 데이터는 어디서 오고 어디에 저장되나

| 데이터 | 출처 / 저장 위치 |
|---|---|
| 장소·행사·사진·상세 | 한국관광공사 TourAPI (`locationBasedList2`, `searchFestival2`, `detailCommon2`, `detailIntro2`, `detailImage2`) |
| 날씨 | Open-Meteo (키 불필요) |
| 현재 위치 | Android 위치(한국 안의 위치만 사용, 밖이면 직접 고른 지역) |
| 찜·아이·취향·장소 후기·최근 본 장소 | 폰 안에 저장. 찜·아이·관심사는 차량 연동용으로 서버(Firebase)에도 올린다 |
| 이야기 글·좋아요·댓글 | Firebase `stories/{코드}`. 지우면 서버에서도 지운다 |
| 차량 연동 | Firebase Realtime Database REST `families/{코드}` |

- 추천은 아이가 고른 취향을 TourAPI 장소·행사와 맞춰 걸러 만든다.
- 찜한 장소는 운영시간·이용연령·편의시설·사진 주소(최대 6장)까지 함께 차량에 올린다.
- 별도 서버 없이 Firebase를 백엔드로 쓰고, 로그인 대신 6자리 연결 코드로 가족을 묶는다. 규칙은 `firebase/database.rules.json`에 있다.

## 내 데이터 지우기

설정의 **내 데이터 모두 삭제**를 누르면 서버에 올라간 찜·아이·추천·연결 정보와 이야기 글이 먼저 지워지고, 성공하면 폰 안의 데이터도 지운다. 서버 삭제에 실패하면 폰 데이터는 그대로 남아서 다시 시도할 수 있다.

## 테스트 환경 및 필요한 설정

| 항목 | 내용 |
|---|---|
| 폰 에뮬레이터 | Pixel 5, Android 17.0 (API 37). 위치 권한은 허용하면 현재 지역 추천이 나온다 |
| 차량 에뮬레이터 | 차량 앱과 연동할 때만 필요. Pleos Connect v2.1.0 APIs, 차량 앱은 짝꿍 저장소의 APK |
| 인터넷 | 필요. TourAPI, 날씨, Firebase를 쓴다 |
| `local.properties` | `TOUR_API_KEY`, `FIREBASE_DB_URL` (소스로 빌드할 때만. 제출한 APK는 필요 없다) |
| Firebase 규칙 | 콘솔 → Realtime Database → 규칙에 `firebase/database.rules.json` 게시 |
| 권한 | 위치(정밀·대략). 거절해도 직접 고른 지역으로 쓸 수 있다 |
| 연결 | **내 정보 → 내 차량**의 6자리 코드를 차량 앱에 입력 |

## 직접 빌드해 보기

1. `local.properties.example`을 `local.properties`로 복사해 값을 채운다.
   ```properties
   TOUR_API_KEY=한국관광공사_API_키
   FIREBASE_DB_URL=https://프로젝트-default-rtdb.firebaseio.com
   ```
2. Firebase 콘솔 → Realtime Database → 규칙에 `firebase/database.rules.json` 내용을 붙여 넣고 게시한다.
3. Android Studio에서 이 폴더를 열고 Gradle Sync를 한다. 실행 대상 `phone`, 기기 폰 에뮬레이터로 Run 한다.
4. release APK는 아래 명령으로 만든다.
   ```bash
   ./gradlew :phone:assembleRelease   # phone/build/outputs/apk/release/
   ```

권한: `INTERNET`, `ACCESS_NETWORK_STATE`, `ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`
API 키와 Firebase 주소는 저장소에 올리지 않는다(`local.properties`는 `.gitignore`에 포함).

## 코드 구성

| 파일 | 내용 |
|---|---|
| `MainActivity.kt` | 화면 전환, 홈·검색·상세·찜·이야기·내 정보, 아이·취향 관리 |
| `Data.kt` | TourAPI 호출, 추천 필터, 날씨 |
| `Extras.kt` | 차량 연동(`FirebaseCarBridge`), 연결 코드, 보내기·상태 확인, 이야기 서버 연동 |
| `MapScreen.kt` | 앱 안 지도 |
| `Settings.kt` | 설정 화면 |
| `Theme.kt` / `Ui.kt` | 색·글꼴·공용 컴포넌트(라이트/다크) |
| `core/` | 차량 앱과 공유하는 Firebase REST 클라이언트 |

사용 라이브러리: Jetpack Compose + Material 3, Coil 2.7.0(이미지), osmdroid 6.1.20(지도, 키 불필요)
